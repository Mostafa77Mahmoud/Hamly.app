# Hamly - Pregnancy Tracking App

## Overview
Hamly is a comprehensive pregnancy tracking and health management application built with Expo (React Native) for cross-platform support. The app provides features for pregnancy tracking, medication safety analysis, lab report processing, and symptom monitoring. Its purpose is to offer a complete solution for expecting mothers.

## System Architecture

### UI/UX Decisions
The application supports both English and Arabic languages, including full Right-To-Left (RTL) support for the Arabic interface.

### Technical Implementations
- **Frontend:** Expo (React Native) with Expo Router for navigation, and React Native Web for web support.
- **Backend:** Supabase handles user authentication and serves as the primary database.
- **Language:** Developed entirely in TypeScript for type safety and maintainability.
- **Development & Deployment:** Configured for seamless development on Replit and deployment via Netlify. The app runs on Node.js 20.
- **Error Handling:** Utilizes `Promise.allSettled` for robust data fetching and an enhanced `ErrorBoundary` to prevent crashes due to partial data failures, including session cleanup for corrupted states.
- **API Robustness:** All backend API calls for AI features (medication safety, symptom analysis, lab processing) are optional and gracefully handle unavailability, providing fallbacks and informative messages in Arabic. It intelligently detects backend availability based on the environment.
- **Mobile Compatibility:** Critical fixes for Android include replacing `performance.now()` with `Date.now()`, improved keyboard handling (pan mode, extra padding, disabled `KeyboardAvoidingView` on Android), protected tracing functions with try-catch, and non-blocking profile creation.
- **Build Process:** Uses SPA (Single Page Application) mode for web builds, optimizes Metro config for production, and includes a build step to remove empty JS files generated by Expo.

### Feature Specifications
1.  **Authentication:** Supabase-based user authentication system.
2.  **Pregnancy Tracking:** Comprehensive tracking of pregnancy weeks, due date, and various health metrics.
3.  **Medication Safety:** Analyzes medication against FDA categories and provides AI-powered safety recommendations.
4.  **Lab Reports:** Allows users to upload and process lab reports with AI-driven analysis.
5.  **Symptom Tracking:** Enables logging and analysis of pregnancy symptoms.
6.  **Bilingual Support:** Full support for English and Arabic languages, including RTL.

### System Design Choices
- **Directory Structure:**
    ```
    ├── app/                    # Expo Router screens (auth, tabs, onboarding)
    ├── components/            # Reusable UI components
    ├── contexts/             # React contexts (Auth, Data)
    ├── services/             # API and service integrations
    ├── utils/                # Utility functions and helpers
    ├── assets/               # Images and static assets
    └── types/                # TypeScript type definitions
    ```
- **Database Schema (Supabase):**
    - `profiles`: User profiles.
    - `pregnancies`: Records related to pregnancies.
    - `medications`: Medication tracking, including safety analysis.
    - `lab_reports` & `lab_results`: Management of lab reports and their results.
    - `symptoms`: Tracking and AI analysis of symptoms.
    - `medication_adherence_logs`: Logs for tracking medication adherence.

## External Dependencies
- **Supabase:** Used for user authentication and as the primary database.
- **Expo (React Native):** Core framework for cross-platform development.
- **Expo Router:** For navigation within the application.
- **React Native Web:** To support web-based access to the application.
- **Netlify:** For continuous deployment and hosting of the web application.
- **AI Backend (Optional):** The app integrates with an external backend API (e.g., via `ngrok` domain `https://al-mugwumpian-patience.ngrok-free.dev`) for advanced AI features such as medication safety analysis, lab report processing, and symptom analysis.
