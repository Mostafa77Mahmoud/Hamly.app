# Hamly - Pregnancy Tracking App

## Overview
Hamly is a comprehensive pregnancy tracking and health management application built with Expo (React Native) for cross-platform support. Its purpose is to offer a complete solution for expecting mothers, providing features for pregnancy tracking, medication safety analysis, lab report processing, and symptom monitoring.

## System Architecture

### UI/UX Decisions
The application supports both English and Arabic languages, including full Right-To-Left (RTL) support for the Arabic interface. UI elements are designed to be responsive, with desktop-aware sizing for welcome screens and refined mobile headers to ensure a clean and consistent user experience. Reusable components like `IconButton` and compact `LanguageToggle` are used for consistent header design.

### Technical Implementations
-   **Frontend:** Expo (React Native) with Expo Router for navigation, and React Native Web for web support.
-   **Backend:** Supabase handles user authentication and serves as the primary database.
-   **Language:** Developed entirely in TypeScript for type safety and maintainability.
-   **Development & Deployment:** Configured for seamless development on Replit and deployment via Netlify. The app runs on Node.js.
-   **Error Handling:** Utilizes `Promise.allSettled` for robust data fetching and an enhanced `ErrorBoundary` to prevent crashes due to partial data failures, including session cleanup for corrupted states.
-   **API Robustness:** All backend API calls for AI features (medication safety, symptom analysis, lab processing) are optional and gracefully handle unavailability, providing fallbacks and informative messages in Arabic. It intelligently detects backend availability based on the environment.
-   **Mobile Compatibility:** Includes critical fixes for Android, such as replacing `performance.now()` with `Date.now()`, improved keyboard handling, protected tracing functions, and non-blocking profile creation.
-   **Build Process:** Uses SPA (Single Page Application) mode for web builds, optimizes Metro config for production, and includes a build step to remove empty JS files generated by Expo. The project also incorporates a professional bilingual onboarding flow with smooth animations using `react-native-reanimated` and `react-native-worklets`.

### Feature Specifications
1.  **Authentication:** Supabase-based user authentication system.
2.  **Pregnancy Tracking:** Comprehensive tracking of pregnancy weeks, due date, and various health metrics.
3.  **Medication Safety:** Analyzes medication against FDA categories and provides AI-powered safety recommendations.
4.  **Lab Reports:** Allows users to upload and process lab reports with AI-driven analysis.
5.  **Symptom Tracking:** Enables logging and analysis of pregnancy symptoms.
6.  **Bilingual Support:** Full support for English and Arabic languages, including RTL, with intelligent layout and text alignment.

### System Design Choices
-   **Directory Structure:** Organizes code into `app/` (Expo Router screens), `components/` (reusable UI), `contexts/` (React contexts), `services/` (API integrations), `utils/` (utilities), `assets/` (static assets), and `types/` (TypeScript definitions).
-   **Database Schema (Supabase):** Includes tables for `profiles`, `pregnancies`, `medications`, `lab_reports`, `lab_results`, `symptoms`, and `medication_adherence_logs`.

## External Dependencies
-   **Supabase:** User authentication and primary database.
-   **Expo (React Native):** Core framework for cross-platform development.
-   **Expo Router:** Navigation within the application.
-   **React Native Web:** Supports web-based access to the application.
-   **Netlify:** Continuous deployment and hosting of the web application.
-   **AI Backend (Optional):** Integrates with an external backend API for advanced AI features (medication safety analysis, lab report processing, symptom analysis).
