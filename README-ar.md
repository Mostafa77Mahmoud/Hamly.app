
# حملي MD - المرافق الذكي للحمل 🤱

## آخر التحديثات
- ✅ **إصلاح حفظ اللغة العربية** - اللغة العربية تحفظ تلقائياً بعد الريفرش
- ✅ **تحسين الأداء** - تحميل البيانات أسرع مع نظام تخزين مؤقت محسن
- ✅ **واجهة محدثة** - تصميم أفضل مع دعم كامل للتخطيط العربي RTL

## نظرة عامة
حملي MD هو تطبيق صحي شامل مصمم خصيصاً لمتابعة الحمل ورعاية الأمهات. يوفر التطبيق تحليل النتائج المخبرية، إدارة الأدوية، تسجيل الأعراض مع الذكاء الاصطناعي، والتنبيهات الصوتية المخصصة.

## الميزات الرئيسية

### 📋 تحليل النتائج المخبرية
- **رفع التقارير**: صور، PDF، أو إدخال يدوي
- **التحليل الذكي**: استخراج النتائج تلقائياً باستخدام Gemini AI
- **تفسير طبي**: شرح القيم والمقارنة بالمعدلات الطبيعية
- **تتبع التقدم**: مراقبة التغييرات عبر فترات الحمل

### 💊 إدارة الأدوية الآمنة
- **تقييم الأمان**: تحليل أمان الأدوية حسب مرحلة الحمل
- **تصنيف FDA**: عرض تصنيفات السلامة الرسمية
- **تذكيرات ذكية**: نظام متقدم لتذكير الجرعات
- **متابعة الالتزام**: تتبع تناول الأدوية يومياً

### 🩺 تحليل الأعراض بالذكاء الاصطناعي
- **تقييم شامل**: تحليل الأعراض حسب أسبوع الحمل الحالي
- **توصيات مخصصة**: إرشادات طبية بناءً على التاريخ الصحي
- **كشف الأنماط**: مراقبة تطور الأعراض والمحفزات
- **تنبيهات طبية**: إنذارات للأعراض التي تتطلب متابعة فورية

### 🎙️ التنبيهات الصوتية المتقدمة
- **تقنية ElevenLabs**: أصوات طبيعية عالية الجودة
- **دعم عربي كامل**: محتوى مخصص باللغة العربية
- **تحديثات أسبوعية**: معلومات عن تطور الحمل أسبوعياً
- **تخصيص كامل**: إعدادات الصوت والسرعة والتوقيت

## النظام التقني

### التقنيات المستخدمة
- **إطار العمل**: React Native مع Expo SDK 53
- **التوجيه**: Expo Router 5.0 للتنقل
- **قاعدة البيانات**: PostgreSQL عبر Supabase
- **الذكاء الاصطناعي**: Google Gemini 2.0 Flash
- **المصادقة**: Supabase Auth مع Row Level Security
- **الاستضافة**: Replit Autoscale

### الأمان والخصوصية
- **تشفير البيانات**: حماية شاملة للمعلومات الطبية الحساسة
- **عزل المستخدمين**: كل مستخدم يصل فقط لبياناته الشخصية
- **مفاتيح آمنة**: إدارة سرية لمفاتيح API
- **تخزين محلي**: نسخ احتياطية محلية للعمل بدون إنترنت

## بدء الاستخدام

### التثبيت السريع
```bash
# تثبيت المتطلبات
npm install --legacy-peer-deps

# تشغيل خادم التطوير
npm run dev:web

# الوصول للتطبيق
# http://localhost:5000
```

### إعداد المتغيرات
قم بإنشاء ملف `.env.local`:
```env
# Supabase (عام)
EXPO_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_anon_key

# AI APIs (خاص - ضعها في Replit Secrets)
GEMINI_API_KEY=your_gemini_key
ELEVENLABS_API_KEY=your_elevenlabs_key
```

## حل مشكلة حفظ اللغة العربية

تم إصلاح مشكلة عدم حفظ تفضيل اللغة العربية بعد الريفرش من خلال:

1. **تحسين آلية التخزين**: استخدام عدة طرق لحفظ تفضيل اللغة
2. **التحقق المبكر**: فحص اللغة قبل تحميل التطبيق
3. **الثبات عبر الجلسات**: اللغة المختارة تبقى حتى يغيرها المستخدم يدوياً

## النشر على Replit

1. **إنشاء workspace جديد** في Replit
2. **استيراد المشروع** من GitHub أو رفع الملفات
3. **إضافة الأسرار** في قائمة Secrets:
   - `GEMINI_API_KEY`: للتحليل الذكي
   - `ELEVENLABS_API_KEY`: للتنبيهات الصوتية
4. **تشغيل التطبيق**: الضغط على Run
